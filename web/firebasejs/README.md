# Local Firebase JS SDK (v12.15.0)

Copied from `https://www.gstatic.com/firebasejs/12.15.0/` so Chrome can boot
when connections to `gstatic.com` are reset.

`web/index.html` remaps those CDN URLs via an import map. If FlutterFire bumps
the supported SDK version, re-download matching files and update the import map.
